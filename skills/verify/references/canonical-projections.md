# Canonical projection boundary

Read the deployed `skills/principles/scripts/project-state.mjs` output and the canonical verification predicates before deciding any field in this package. `transition:`, `event:`, `product:`, and `complete:` are raw authorities; capability invocation adds the tool’s capability revision and baseline detail.

The package may record the raw values, but it does not create a replacement state tool, status vocabulary, or verification predicate. A missing or unparseable canonical projection is a blocking observation, not a guessed value.

For C2, a closed research card remains raw evidence and current synthesis stays with its nearest owner/K. For C5, descend into closed history only through the named card, non-pass repair lineage, or current K/Trap Source basis. For C6, shared source locators and all residual owner markers must be consumed before closure.
