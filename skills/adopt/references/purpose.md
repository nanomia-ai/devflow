# Adopt purpose

Adopt converts evidence already present in an unmanaged brownfield repository into devflow's canonical planning surface. Its source of truth is maintained pre-devflow material—documentation, code, specifications, schemas, tests, configuration, or operational records—not a fresh greenfield interview.

The result is a faithful and complete projection of the existing product boundary, architecture, applicable design strategy, code conventions, vocabulary, capability design zones, and durable domain knowledge. Every maintained source is accounted for; extensive domain documentation produces the owner-adjacent knowledge nodes it needs instead of being sampled away. Human attention is reserved for genuinely missing decisions, unresolved contradictions, and final approval.

Adopt does not own general session routing. It is entered explicitly, consumes `setup.unmanaged` only for this purpose, leaves no artifacts on refusal or interruption before approval, and finishes without automatically starting another skill.
