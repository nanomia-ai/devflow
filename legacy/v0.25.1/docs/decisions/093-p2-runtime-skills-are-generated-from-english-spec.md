# DD-93 · P2 런타임 스킬은 영문 `spec.mjs`와 `body.md`에서 생성되고, 한글 legacy atom은 이관 출처만 보존한다

- 상태: 유효 · 일부 정정 → DD-115 (v0.26.0)
- 주제: 정체성 · 배포 · 플랫폼
- 도입: v0.20.0
- 날짜: 2026-08-30

관찰된 충돌: DD-16의 한글 설계 원본 규칙을 P2 런타임 패키지에도 그대로 적용하면 생성기가 읽지
않는 새 한글 행동 원본이 생기며, DD-92의 `spec.mjs` 유일 행동 원본 표현은 `body.md`가 소유한
산문 의무를 누락한다.

선택 경계와 반박: 소유자가 직접 검토하는 문서와 Codex adapter의 선언된 한영 쌍은 계속 한글을
먼저 고치고 1:1로 검토한다. P2 런타임 스킬만은 영문 `spec.mjs`와 `body.md`가 실행 작성 정본이고,
`SKILL.md`와 `.generated.json`은 그 생성 투영과 영수증이다. `references/legacy-atoms/`의 한글 원자는
이관 출처를 보존할 뿐 살아 있는 쌍이나 행동 원본이 아니다. 따라서 DD-16의 소유자 검토 이유는
남은 선언 쌍에는 유효하지만, 생성기가 영문 원본만 소비하는 P2 런타임에는 두 번째 집을 정당화하지
못한다.

영향 좌표: DD-16·DD-92, 문서 지도, `AGENTS.md` 한영 경계, 유지보수 절차 §2, P2 패키지의
`spec.mjs`·`body.md`·생성 `SKILL.md`·legacy provenance. 재검토: 소유자가 런타임 문구를 직접
검토해야 하거나 생성기가 한글 원본 또는 legacy atom을 행동 입력으로 소비하게 될 때.
