# DD-58 · 끝난 카드의 번호는 다시 매기지 않는다

- 상태: 유효
- 주제: 작업 트리와 카드
- 도입: v0.13.0
- 날짜: 2026-08-13
- 날짜 근거: git 추정 (CHANGELOG에 해당 버전 없음)

초안은 번호가 중복되면 완료 카드도 중간 삽입 형식으로 옮기고 의존을 갱신하게 했다. 그런데 완료된 번호는 커밋 제목·외부 CI·이슈·사람의 링크에도 남고, 파일과 의존만 고쳐서는 그것들에 닿지 않는다. 두 완료 카드가 이미 같은 번호로 외부에 알려졌다면 어느 참조가 어느 카드인지 일반적으로 복원할 수 없다. 그리고 번호가 통합에서만 발급되므로 중복은 이제 대기·미점유 단계에서만 생기고, 그 단계에서는 재번호화가 싸다. 그 뒤로는 정합성 이상으로 보고한다
