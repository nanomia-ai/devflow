# Retrospective event lifecycle

Create the canonical pending retrospective record before the clean, artifact-only role
dispatch and resume that same event after interruption. Preserve source id, event timestamp,
and event key through findings, user decision, and one-at-a-time adopted-finding routing;
zero findings completes without a fabricated alternative.

Retrospective is a post-hoc design alternative event. It does not block a verification verdict
or transition, and a capability event does not infer a cross-capability conflict outside an
exact supplied Consumed-path relation.
