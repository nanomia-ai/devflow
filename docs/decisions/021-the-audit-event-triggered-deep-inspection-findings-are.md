# DD-21 · 감리(audit) — 사건 발동 깊은 점검, 소견은 판정이 아니다 (v0.9.15, 범위 수정 v0.9.21)

- 상태: 유효
- 주제: 검증과 역할
- 도입: v0.9.15
- 최종 검토: 2026-09-11

근거는 소유자 실전 보고(2026-08-10, ade 운용): 단회 결과가 허점을 남기고, 실수가 실수로 인식되지 않은 채 검증을 통과한다. 관찰 항목 둘(능력층 표본 폭·MVP 스펙 맹점)의 이행. 상시 단계가 아니라 세 사건(제품층 1회 · 실패를 기록한 능력의 폐쇄 · 사용자 요청)만 발동 — "겪은 결함이 있을 때만 자란다"의 런타임 적용이라 깨끗하게 닫힌 능력은 비용 0. 수렴 장치: 비차단 소견 · 영 소견 유효 · 사용자 채택만 카드화 · 재폐쇄 무재실행(새 유출은 새 사건). v0.9.15의 읽기 범위인 "실행한 경로 + 능력 폴더"는 현재 구조를 대표한다는 전제가 브라운필드·평면 구조에서 성립하지 않고 카드 이력을 노출하면서 아직 실행하지 않은 현재 표면은 놓친다. 그래서 v0.9.21은 과거 commit·diff·카드 대신 arch가 정확히 매핑한 경로 또는 외부 진입점부터 공유 계약 경계까지의 현재 능력 코드 범위로 제한한다. 이중 독립 검증(반증 워크 · 전체 정합 감사)이 초안에서 방아쇠 앵커 오독(덮어쓰기로 사멸/영구 재발화) · 무유계 읽기 · 품질 사냥감(단순화 카드 先실험 계보 미반박)을 적출해 수리·삭제한 뒤의 채택
