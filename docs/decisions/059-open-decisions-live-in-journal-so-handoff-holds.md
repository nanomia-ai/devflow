# DD-59 · 열린 결정은 journal에 살고, HANDOFF에는 트리가 다시 계산하는 것만 남는다

- 상태: 유효
- 주제: 지식층과 능력 문서
- 도입: v0.13.0
- 최종 검토: 2026-09-11

v0.7.0은 열린 결정을 journal로 옮기는 것을 "한 개념 두 집"으로 기각했는데, HANDOFF에서 그 절을 통째로 없애면 집이 정확히 하나가 되므로 그 사유가 반박된다. 지금 닫는 실패는 구체적이다 - HANDOFF는 통째로 덮어쓰고, 한 사람의 두 세션이 방 하나를 공유하며, 둘 다 덮으면 한쪽의 결정이 흔적 없이 사라진다. journal은 덧붙이기만 하고 이탈 경로에서 이미 기명 열린 결정을 받고 있었다. HANDOFF에 남는 `다음 한 걸음`은 정본 후보 순서가 다시 계산하므로, 덮어써서 잃는 것은 순서 선호이지 자료가 아니다
