# DD-53 · 한 작업 폴더의 여러 세션은 정상이고, 그 안전은 락이 아니라 측정된 다섯 줄이다

- 상태: 유효
- 주제: 동시성 · 점유 · 통합
- 도입: v0.13.0
- 최종 수정: 2026-08-13

소유자가 매일 하는 방식이 한 능력의 세부 기능을 터미널 여럿으로 나눠 도는 것이므로 이것을 막으면 도구의 목적이 사라진다. 측정 결과 충돌 지점은 셋뿐이고 셋 다 락 없이 닫혔다 - 자기 경로를 지정한 커밋은 다른 세션이 stage해 둔 파일이 있어도 자기 것만 담고, 네 세션이 동시에 기록장에 덧붙여도 한 줄도 잃지 않으며, 열린 결정을 journal로 옮기면 HANDOFF에는 트리에서 다시 계산되는 값만 남아 경합 자체가 사라진다. 공유 소스 파일에 관해서는 한 폴더가 두 폴더보다 오히려 안전하다 - 부분 수정은 상대가 이미 쓴 것 위에 얹히지만, 워크트리로 나누면 같은 충돌이 사람의 병합으로 미뤄진다. 조용히 덮는 것은 통째 쓰기뿐이라 그것만 한 줄로 막는다. 여기에 막는 문장은 없고 전부 "이렇게 하면 안 깨진다"이다
