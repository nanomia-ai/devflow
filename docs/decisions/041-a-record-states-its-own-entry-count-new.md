# DD-41 · Record는 자기 항목 수를 기술한다 — New entries

- 상태: 유효
- 주제: 검증과 역할
- 도입: v0.9.23
- 최종 수정: 2026-08-13

판정 직후·커밋 전에 죽은 세션의 부분 Record가 완성본인지 디스크만으로 판정할 수 없었다 — 요구되는 항목의 총수가 죽은 세션의 컨텍스트에만 있었다. 자기 기술 필드가 완성 판정을 기계화한다. 값이 맞지 않으면 부분 작성으로 판정되어 2단계부터 반복하는 승인된 재실행 경로로 회복한다. 커밋된 무필드 Record는 커밋으로써 완성본이다 — 부재를 관용하는 이 처리는 verification-predicates의 pre-v0.9.21 기록과 같은 부류다
