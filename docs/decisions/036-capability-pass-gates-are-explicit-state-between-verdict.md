# DD-36 · 능력 통과 게이트는 판정과 폐쇄 사이의 명시 상태이고, 폐쇄는 검증 revision 입력을 바꾸지 않는다

- 상태: 유효
- 주제: 검증과 역할
- 도입: v0.9.21
- 최종 수정: 2026-08-13

verifier 통과 직후 세션이 끊겼을 때 성공 판정만 보고 폐쇄하면 표준·잠정값 게이트를 건너뛴다. 반대로 폐쇄 중 core 문서를 바꾸면 방금 계산한 revision이 즉시 낡는다. 따라서 현재 통과에는 두 게이트의 현재 결과가 필요하고, 폐쇄는 `verify.md` 기록 → `journal.md` 기록 → 능력 폴더 `.done` rename 순서만 수행한다. core 문서로 가야 할 journal 결정은 검증 전에 소유 skill로 보내며, 늦게 발견한 결정은 marker를 보존하고 revision 판정부터 다시 실행한다
