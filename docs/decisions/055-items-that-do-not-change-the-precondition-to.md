# DD-55 · 전제→결과 전이를 바꾸지 않는 항목들은 카드 하나에 함께 탄다

- 상태: 유효 · 일부 정정 → DD-61 (v0.14.0)
- 주제: 작업 트리와 카드
- 도입: v0.13.0

devflow에는 작업이 커 보일 때의 승격은 있는데 작을 때의 출구가 없어 버튼 색 하나에도 기록 - 매핑 - 카드 - 제안 - 승인 - 점유 - 고정 읽기 - 구현 - 신호 - 검토 - 커밋 - 경계를 전부 태웠다. 소유자가 벗어나려 했던 무거움이 그대로 재현된다. 기준을 새로 만들 필요는 없었다 - 기준선 판정 정본이 이미 전제와 결과가 그대로면 버튼 이름·문구·배치 변경을 제외하고 있어서, 같은 선을 작업층에도 쓰는 것뿐이다. 묶는 것은 빼는 것이 아니다. "작으니까 기록 안 함"은 만들지 않는다 - 기록되지 않는 경로가 하나 생기면 그것이 기본길이 되고, 자산이 될 데이터의 지속적 누락이 된다. **v0.14.0에서 정정**: 그 경계의 절반이 반증으로 물러났다 — 커밋이 곧 기록인 경량 변경(tweak)은 문서 기록 없이 커밋 하나로 끝난다. 묶기는 게이트를 통과하지 못하는 작은 항목들에 남는다(경량 변경 행 참조)
