# DD-38 · `승인`의 유효성은 카드 값만이 아니라 Git diff 신선도까지 요구한다

- 상태: 유효
- 주제: 작업 트리와 카드
- 도입: v0.9.21
- 최종 검토: 2026-09-11

실패 경로: 카드가 승인 뒤에 바뀌어도 낡은 승인이 그대로 남아, 사용자가 보지 않은 목적지·금지·완료 신호가 점유된다. 그래서 승인은 authority(솔로 HEAD 또는 fetch한 다중 통합 브랜치)에 같은 경로가 있고 index·working tree가 그 authority와 Git 정규화 비교에서 모두 같을 때만 유효하다
