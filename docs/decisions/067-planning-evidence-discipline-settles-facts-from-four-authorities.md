# DD-67 · 기획 증거 규율은 네 권위의 사실을 질문 전에 닫고, 답만 필요한 조사는 격리하되 구조 이해와 구속 결정은 메인이 소유한다

- 상태: 유효
- 주제: 지식층과 능력 문서
- 도입: v0.15.0
- 최종 검토: 2026-09-11

product·arch·adopt·split은 현재 저장소 사실·외부 계약 사실·실행 사실·소유자 결정을 같은 미지수처럼 다뤄, 환경이 답할 사실을 사용자에게 묻거나 최신 문서로 고정 버전을 증명하는 경로가 있었다. 네 권위를 나누고 질문 전에 허용된 범위의 사실을 먼저 확인한다. 사용자가 명시한 조사는 요청 범위로, 자동 조사는 가능한 결과가 현재 후보·추천 기본값·Layer 0 필드·검증 가능성 중 하나를 바꿀 때로 유계한다. 결론·영향·정확한 출처는 기존 소유 문장에 남기되 원시 조사 문서는 만들지 않는다

답만 필요한 내부·외부 근거 탐색이 새 경로·출처 추적이나 대조·반복을 요구하면 같은 탐색 범위의 질문을 읽기 전용 조사자 하나에 격리한다. 조사자는 실행·prototype·파일 쓰기·재위임·결정을 하지 않고 정지 상태와 근거 좌표만 반환한다. 대표 흐름·코드 구조·문서 구조·도메인 맥락 같은 원자료 이해는 메인이 소유하고, 조사 결과를 받은 메인은 핵심 좌표만 확인한 뒤 영향 판단과 구속 결정을 맡는다. product·arch·adopt는 동반 정본을 진입 시 읽고 split은 유지보수 기획 깊이 등급을 판정할 때 필요한 절만 읽는다. work·verify·resume과 역할 컨텍스트는 소비자가 아니므로 고정비를 받지 않는다
