# DD-20 · 브라운필드 진입은 전용 스킬 adopt — arch에서 분리

- 상태: 유효
- 주제: 브라운필드와 진입
- 도입: v0.9.10
- 최종 수정: 2026-08-13

arch가 개발 기획과 Layer 0 전체 역산이라는 두 개념을 한 이름에 담아, 진입 발견성이 죽고(역산 트리거가 스킬 설명 꼬리에만 존재) 본문 접합부가 모호했다(역산 뒤 인터뷰 절차·검증 창구 게이트의 적용 여부를 문자적 독자가 확정 못 함 — 소유자 지적 2026-08-10). 역산 절차와 필드 배분은 0.9.8 결정 그대로 이동 — 신규 문장은 진입 가드·증거 서열·게이트 포인터·design 한 줄로 유계, 0.9.8의 "재인터뷰는 낭비" 판정 유지. 산출 형식의 정본은 product·arch에 남고 adopt는 단계명 참조 + Codex 프롬프트는 설치기가 동봉(평면 폴더 결정과 같은 근거). adopt는 개발 문화의 표준 어휘다 — Nx 문서 절 "Adopting Nx", Next.js·React 공식 "Incremental Adoption", Tech Radar 최상위 링 "Adopt"
