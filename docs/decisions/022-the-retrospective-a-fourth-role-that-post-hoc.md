근거는 소유자 증언(2026-08-10): AI는 자기 기획을 의심하지 않고, reviewer/verifier는 명확한 문제만 집으며, 더 나은 선택지는 아무도 묻지 않는다 — 감지가 스스로 일어나지 않으므로 "단순화 카드 먼저 실험" 관찰 항목의 전제(사용자가 알아챈다)가 반박된다. 판단어("더 나은")는 3요건으로 유계: 구체적 대안 명명 + 이 프로젝트의 긴장 증거 필수(수정 카드 밀도·`.stale.`·ADR 갱신 주석·미해소 잠정값 — 산출물에서 관측 가능한 것만; 반증이 초안의 탈출 카드·잠정값 이력을 관측 불능으로 적출해 삭제) + 전환 비용 추정 표시. 입력은 devflow 산출물뿐, 코드 0 — 읽기 완전 유계. auditor 2모드 겸용은 기각(맹검 축이 정반대 — 한 이름 두 개념). 발동은 제품층 판정 기록 뒤 1회 + 사용자 요청뿐, 비차단·영 소견 유효·채택만 카드/재기준선 (발동 목록은 v0.9.17에서 능력 첫 폐쇄가 추가됨 — 그 행 참조)
