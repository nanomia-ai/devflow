# DD-29 · 플랫폼 어댑터는 공통 스킬로 연결만 하고 절차를 복제하지 않는다

- 상태: 유효 · 일부 정정 → DD-92 (v0.20.0)
- 주제: 정체성 · 배포 · 플랫폼
- 도입: v0.9.21

Claude·Codex의 의미 규칙은 같은 SKILL.md와 역할 계약이다. Codex 폴백 AGENTS가 resume의 일부 절차를 복제해 journal·신선도·정합성 점검을 빠뜨렸고, 훅도 Layer 0 다음 단계를 별도로 판정했으며, 로컬 설치기는 플러그인 훅과 구형 전역 훅을 함께 등록했다. 폴백과 훅은 공통 resume으로만 연결한다. 훅은 파일 내용·HANDOFF·다음 단계 판정을 주입하지 않는다. 설치기는 네이티브 플러그인 성공 뒤에만 정확한 구형 등록을 제거해 교체 실패 때 작동 중인 훅을 보존한다. 손상된 `owner.md`가 있어도 다중 모드는 유지하되, 유효한 자기 방이 해결되면 그 방은 쓸 수 있고 해결되지 않은 세션만 읽기 전용이다. 이는 플랫폼별 정책 추가가 아니라 동일 계약의 전송 수리다
