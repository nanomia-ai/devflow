# DD-57 · Codex 평면 프롬프트 채널을 없애고 플러그인 캐시가 동반 문서를 나른다

- 상태: 유효 · 일부 정정 → DD-92 (v0.20.0)
- 주제: 정체성 · 배포 · 플랫폼
- 도입: v0.13.0
- 최종 수정: 2026-08-30

실측(2026-08-13): Codex는 플러그인을 `~/.codex/plugins/cache/<마켓플레이스>/<플러그인>/<버전>/`에 저장소 전체로 설치하고, 모델은 그 절대 경로에서 자기 스킬을 읽는다 - 따라서 `../principles/SKILL.md`가 Claude에서와 똑같이 풀린다. 내장의 기록된 이유("Codex 프롬프트 폴더는 평면이라 상대 참조가 불안정하다")는 `~/.codex/prompts/`에 대해서는 참이지만 플러그인에는 미치지 않는다. 프롬프트 8개는 각각 규칙집 전체를 내장해 50-120KB였고 설치기 둘이 각자 내장 로직을 갖고 있어 규칙을 고칠 때마다 두 번 맞춰야 했다. 생성만 지우면 이전 파일이 계속 호출 가능하므로, 정리는 생성 표식으로 가려 정확한 8개 이름만 한 릴리스 동안 지우고 사용자가 그 이름으로 직접 쓴 파일은 남긴다
