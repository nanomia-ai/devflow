# DD-46 · 모드는 하나 — 방은 항상 있고, 혼자 쓰면 통합 브랜치가 지금 쓰는 브랜치로 접힌다

- 상태: 유효
- 주제: 동시성 · 점유 · 통합
- 도입: v0.12.0
- 최종 수정: 2026-08-13

솔로/다중 두 갈래는 **동시에 흐르는 작업**을 한 번도 모델링하지 않았다. 사람 하나 = 흐름 하나라는 가정 때문에 터미널 두 개가 곧 정합성 이상이었다. 모드 분기는 8개 파일 59줄이었고 솔로는 그 줄을 전부 읽은 뒤 "무시하라"는 말만 들었다 — 읽기 비용은 같고 결정만 늘었다. 통합해도 혼자 쓰는 비용은 **카드당 커밋 하나**(점유 커밋)뿐이고, 그 커밋이 곧 워크트리·다중 터미널 지원의 열쇠다. `integration`이 현재 브랜치를 지목하면 통합 tip이 HEAD이고 fetch·push·통합 지시가 전부 통상 커밋으로 접힌다 — 로컬만 있는 통합 브랜치에는 네트워크 명령도 필요 없다. 이 통합이 v0.9.23의 "솔로는 묶음 통째, 다중은 하나씩"을 뒤집는다: 그 분리의 근거였던 "진입 규칙 하나로 닫는다"는 모드가 사라지면서 같은 승인이 두 소비 방식을 다 허가하는 것으로 족해졌고, 분리 자체가 모드 분기의 산물이었다. v0.9.21이 기록한 승인 신선도의 근거는 그대로이고 그 authority 표현만 통합 tip 하나로 줄었다. Git 작업 트리 밖은 축소 동작으로 명시한다
