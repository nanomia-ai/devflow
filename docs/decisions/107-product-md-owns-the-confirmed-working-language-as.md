# DD-107 · product.md가 확인된 작업 언어를 한 사실로 소유하고 Principles가 모든 작성자의 산문 일관성을 지킨다

- 상태: 유효
- 주제: 지식층과 능력 문서
- 도입: v0.23.15
- 최종 검토: 2026-09-11

관측된 문제: 실제 Adopt 산출물에서 한국어와 영어 산문이 섞였지만, 어느 언어를 이후 사람과 AI의
유지보수 기준으로 삼을지 제안하거나 확인하는 표면이 없었다. 현행 영문 런타임 안내와 예시는 내용
언어까지 영어라는 압력을 만들 수 있고, DD-91의 “프로젝트 언어 정본”은 glossary의 정확 용어를 뜻할
뿐 산문 언어 선택을 소유하지 않는다. 각 단계가 문서나 glossary에서 다시 추론하면 다국어·동률·희박한
자료, 외국어 정본 용어가 있는 프로젝트, 소유자가 자료와 다른 언어를 고른 경우에 확인된 답을 잃는다.

선택한 경계: `.devflow/project/product.md`의 정체성 바로 뒤 정확한
`Working language: <소유자가 확인한 설명>` 한 줄이 프로젝트 작업 언어의 유일한 영속 값 소유자다.
값은 닫힌 언어 열거가 아니며 단일 언어나 소유자가 정한 다국어 관례를 설명할 수 있다. Adopt는 유지
문서·코드 주석·명세·운영 기록의 의미 있는 사람 산문을 조사해 우세 언어를 제안한다. 명시한 소유자
선호가 우선하고 코드/API 식별자·경로·생성물·vendor text 같은 기계 토큰은 표가 아니며, 동률·실질적
다국어·희박·부재 증거는 거짓 다수 대신 불확실성으로 드러낸다. Product는 도입할 자료가 없는 새
프로젝트에서 소유자 대화로 같은 값을 자연스럽게 제안한다. 두 단계 모두 정본 쓰기 전에 제안을
보여 주며 교정은 승인이 아니다. Product는 기존 쓰기 없는 ask 재진입으로 수정 제안을 다시 보여 주고,
Adopt는 수정된 전체 제안에 새 독립 의미 반증을 거친 뒤에만 기존 쓰기 없는 prepare 재진입으로 돌아간다.

Principles의 모든 단계가 항상 읽는 prompt policy가 후속 작성과 수정의 의미 산문을 확인된 값에
맞춘다. 고정 schema heading·key, path·slug, command, API·code identifier, provenance literal, 정확한
source·정본 domain term은 각 계약대로 보존하고, 인용 원문은 원문 언어를 유지한다. 따라서 glossary
key와 `Concepts:`는 정확 용어를 유지하면서 정의와 종합 산문만 작업 언어를 따른다. 이 한 줄이 없는
기존 관리 프로젝트는 유효하며, 줄을 추가하려고 문서를 다시 쓰지 않는다. Product가 다음에 그 선택을
재확인할 때까지 각 대상 artifact의 이미 일관된 산문 언어를 보존한다.

필요한 이유와 기각: Product는 이미 모든 후속 단계가 읽는 프로젝트 정체성·현재 계획의 소유자이고,
Principles는 이미 모든 P2 진입이 한 번 읽는 공통 정책 소유자다. 따라서 값 하나와 행동 하나가 각자
한 집에 산다. 이는 소비자 없는 관측 cache를 기각한 DR-14와 다르다. 새 줄에는 이름 난 전 소비자가
있고 상태 도구가 parse하거나 route하지 않는다. glossary metadata, 단계별 재추론, 문서마다 language
field, scanner·registry·crawler, 닫힌 언어 목록, 식별자 번역, 전역 의미 validator는 중복 소유·오판·
무유계 비용을 만들므로 채택하지 않는다.

영향 좌표: Principles prompt policy와 capsule provenance 문장, Product와 Adopt의 spec·본문·제안 및
product template·표적 계약 test, 모든 P2의 기존 shared-policy/product 소비 edge, DD-91·DD-97, 매트릭스
§3.18·§3.24, 한영 설계 쌍·고정 용어·배포 manifest·CHANGELOG·v0.23.15 보고. 상태 도구·새 marker·
언어 scanner·다른 단계의 source는 바뀌지 않는다.

재검토 조건: 확인된 줄을 읽은 후속 작성자가 다시 산문 언어를 섞거나 고정 토큰을 번역하는 실제 장면,
유효한 기존 프로젝트가 줄 부재만으로 차단되는 장면, 또는 의미 있는 산문 근거와 소유자 교정을 거친
Adopt 제안이 반복적으로 잘못된 우세 언어를 고르는 장면이 관측될 때.
