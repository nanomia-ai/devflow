# DD-65 · 혼합 요청은 게이트 탈락 항목만 기록한다 — 통과 항목은 journal 줄에 적히지 않는다

- 상태: 유효
- 주제: 작업 트리와 카드
- 도입: v0.14.2

v0.14.0 감사(소견 4.1)가 동시 충족 불가를 증명한 4조건 — 항목별 분류 · 경량은 카드도 journal도 만들지 않음 · 원 요청 줄은 계획 커밋이 한 번에 삭제 · 어느 시점에 죽어도 항목별 완료를 디스크만으로 복원 — 의 해소다. 통과 항목이 기록 줄에 섞이면 카드도 기록도 얻지 못한 항목이 소비만 되어 중단 시 흔적 없이 사라진다(1계층 소실 경로). 소유자 원칙 "경량은 어떤 기록도 만들지 않는다"에 따라 넷째 조건의 요구를 통과 항목에서 거둔다: 기록 줄은 게이트 탈락 항목만 담고, 통과 항목은 그 대화에서 경량 차선이 처리한다(기록 커밋이 먼저, 경량 커밋이 그 다음) — 어떤 도착 모양에서든 경량 항목의 대접이 하나로 같아진다. 기록 직후·경량 실행 전에 죽으면 통과 항목이 대화와 함께 사라지는 창이 남는데, 이는 순수 경량 요청의 중단과 같은, DD-61이 이미 수용한 등급이다. 카드 동승안(통과 항목도 카드에 실어 완전 내구)은 그 원칙과 정면 모순이라 소유자가 기각했고, 내구 항목 목록안(항목 id·종류·완료 커밋의 새 정본 형식)은 소비자·병합·중단 복구·이관이 함께 필요한 새 상태 기계라 보류다. split의 경량 되돌려보내기 문장은 삭제됐다 — 기록된 줄에 통과 항목이 없으므로 존재 이유가 없다
