# DD-27 · `.stale.` 작업 카드는 역사로 남고 `재분할 대기` 마커가 교체 계획 전 중단을 복구한다

- 상태: 유효
- 주제: 작업 트리와 카드
- 도입: v0.9.21
- 최종 검토: 2026-09-11

회고는 `.stale.` 카드를 긴장 증거로 읽는데 폐쇄 규칙은 모든 자식을 `.done`으로 요구하고 제품 완료 조건은 `.stale.` 자체를 금지해, 정상적인 상위 결정 변경 한 번이 영구 미완료를 만들었다. `.stale.` 작업 카드는 삭제하지 않고 활성 자식 계산에서 제외하되, 폴더가 닫히려면 활성 직계 자식이 하나 이상 있어야 한다. 상위 결정은 직계 부모 폴더별 정확한 `재분할 대기` 마커를 먼저 남기고, split이 사용자 승인된 교체 카드 계획을 착지할 때만 지운다. work는 최종 작업 커밋 전에 현재 카드의 무효 여부를 판정하며, 무효면 완료 커밋 대신 wip 체크포인트로 이 경로에 들어온다. 따라서 중단 뒤에는 마커가 재분할을 재개하고, 계획 뒤에는 보존된 `.stale.`가 완료를 막지 않는다
