# DD-115 · 언어 규칙은 한 줄이다 — skills 는 영어, docs 는 한국어, CHANGELOG 는 영어

- 상태: 유효
- 주제: 정체성 · 배포 · 플랫폼
- 도입: v0.26.0
- 날짜: 2026-09-11

관측된 문제: 정본 넷(`design`·`backlog`·`direction`·`maintenance-protocol`)이 `_ko`/영문 쌍이었고,
1결정 1파일 이행 뒤에는 결정 111 개도 쌍이 되어 **222 파일**이 됐다. 합계 약 720 KB 가 같은 뜻의
두 벌이고, 시험 15 군데가 그 두 벌이 갈리지 않는지 감시하고 있었다.

**이것은 문자 그대로 「한 사실 두 집」이고, 이 저장소가 존재하는 이유인 규칙을 문서 체계 자신이
어기고 있었다.** 규칙 하나를 고치려면 두 곳을 고치고, 시험이 구조 대칭만 볼 수 있으므로 **뜻이
갈리는 것은 아무것도 잡지 못한다.** 그리고 비용이 누적 고정비다 — 결정이 하나 늘 때마다 파일이
둘 늘고, 번역 단계가 하나 늘고, 감시 대상이 하나 는다.

동시에 반대 증거가 이미 있었다: 한국어 전용인 셋(`audit-guideline`·`usecase-matrix`·
`working-method`)이 이 저장소에서 가장 크고 가장 잘 쓰이는 계기인데, 짝이 없다고 문제가 된 적이 없다.

원하는 동작: 언어가 **표면의 성질**로 결정되고, 규칙을 외울 필요가 없다.

선택한 경계: 규칙은 한 줄이다 — **`skills/` 는 영어, `docs/` 는 한국어, `CHANGELOG.md` 는 영어.**

- `skills/` 와 `codex/` 는 전 세계 사용자 프로젝트에서 **다른 AI 가 읽는 제품**이므로 영어다.
- `CHANGELOG.md` 와 `docs/changelog-archive.md` 는 **공개 저장소의 출하 이력**이므로 영어다.
- `docs/` 는 소유자와 유지보수 세션이 읽는 **작업면**이므로 한국어이고 짝을 두지 않는다.
- `AGENTS.md` 는 두 진영이 함께 들어오는 **진입면**이라 영어를 유지한다.

`_ko` 접미사도 함께 사라졌다: 구분할 짝이 없으면 의미가 없다. 파일은 `design.md`·`backlog.md`·
`direction.md`·`maintenance-protocol.md`·`audit-guideline.md`·`usecase-matrix.md`·
`working-method.md` 이고 결정은 `docs/decisions/` 에 한 결정 한 파일이다(이 릴리스 끝에 116).

짝 정합을 감시하던 시험은 **감시 대상과 함께 사라지고**, 대신 새 규칙 하나를 지키는 시험이 선다 —
`skills/**` 에 한글이 없고(legacy-atoms 제외), `CHANGELOG` 계열에 한글이 없고, `docs/**` 가
한국어인지. **규칙을 바꿨으면 벽도 새 규칙을 지켜야 한다.**

경계가 필요한 이유: 짝은 드리프트를 막으려고 시험을 부르고, 그 시험은 구조만 볼 수 있어서
정작 뜻의 드리프트는 못 잡는다. 즉 **비용은 확실하고 이득은 부분적**이다. 한 사실 한 집으로 가면
드리프트 경로 자체가 없어지므로 감시할 것도 없다 — 이 저장소가 결정 색인(DD-84)과 런타임 투영에서
이미 두 번 택한 형태와 같다.

기각한 대안: **짝을 유지하고 시험을 강화** — 뜻의 대응을 기계가 검사할 수 없으므로 강화할 수 있는
것은 구조뿐이고, 그것은 이미 하고 있었다. **docs 를 영어 단일로** — 소유자가 검수하는 작업면이고,
소유자가 한국어로 판단한다. 검수면을 잃는 대가가 공개성보다 크다. **결정만 한국어, 정본은 짝 유지** —
경계가 둘이 되어 「어느 것이 짝인가」를 다시 외워야 한다. 한 줄 규칙의 값이 사라진다.

영향 좌표: `docs/**` 전부(파일명과 언어), `docs/decisions/`(ko 하위 제거),
`scripts/decision-index.mjs`(`--lang` 제거), `scripts/repository-invariants.test.js`(짝 검사 제거,
언어 규칙 검사 신설), `scripts/decision-index.test.js`, `AGENTS.md` 경계 절,
`docs/maintenance-protocol.md` §2, `docs/design.md` 문서 지도.
재검토 조건: 외부 기여자가 `docs/` 를 읽지 못해 기여가 막히는 것이 실제로 관측될 때. 그때 답은
짝을 되살리는 것이 아니라 그 문서 하나를 영어로 옮기는 것이다.
