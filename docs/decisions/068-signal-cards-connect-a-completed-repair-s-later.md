# DD-68 · 신호 카드는 완료된 수리의 후속 non-pass를 같은 root에 연결하고 직전 수리 증거를 상속하며 재관측 2 이상에서 사람에게 돌아간다

- 상태: 유효 · 일부 정정 → DD-81 (v0.18.9)
- 주제: 검증과 역할
- 도입: v0.15.0
- 날짜: 2026-08-14

verifier가 실행한 현재 회귀 label을 `신호 카드`로 실패 이력에 보존하고, 완료된 수정 카드 번호를 기존 verify key·출처 id의 root에 역색인한다. verifier 전에 현재 대상·트리 루트·label 능력의 verify.md 세 경로만 기계 투영해 label별 후보 root를 0·1·2 이상으로 판정한다. 한 실행의 항목은 독립 기록하고 같은 root 항목만 한 재관측 수를 공유하며, 한 label의 후보가 둘 이상이거나 저장 필드가 해석되지 않으면 의미로 고르지 않고 실행·결과 기록을 모두 멈춘다. UUID·증상 유사성·typed evidence graph는 만들지 않으므로 DR-08의 기각 사유를 다시 열지 않는다.

새 수정 카드는 현재 신호 카드와 같은 root의 직전 완료 수리 라운드가 남긴 모든 route 카드의 합집합만 정본 카드 번호 순서로 읽는다. split은 최종 route operations 뒤 각 카드의 정확한 경로를 기존 `읽을 것`에 넣고, `왜`에는 현재 non-pass와 직전 수리가 신호를 pass로 만들지 못한 결과를 쓰며, 동일 접근 반복의 직접 근거가 있을 때만 `금지`를 쓴다. 별도 원인 문서나 work 방법을 강제하지 않아 DR-09를 유지한다. 새 root와 재관측 1은 현행 수정 route, 재관측 2 이상은 자동 카드 없이 사람 관문으로 보내고 이후 non-pass도 같은 관문으로 돌아간다. 구형 항목을 소급 보강하지 않으며, 폐쇄 지식은 현재 카드와 직접 `읽을 것`을 이미 수확하는 기존 능력 지식 기준선 전면 갱신이 소유한다.
