# DD-35 · Commit locator는 Git의 전체 object ID를 쓰고 경로·카드 순서는 byte·숫자 규칙으로 정본화한다

- 상태: 유효
- 주제: Git 기계와 중단 복구
- 도입: v0.9.21

40자리 고정은 SHA-256 저장소를 거부한다. 운영체제·모델의 기본 문자열 정렬은 Unicode 경로와 `02.2`·`02.10`·`02.2b`에서 다른 첫 항목을 고를 수 있다. Git이 출력한 축약하지 않은 object ID, 저장소 상대 `/` 경로의 UTF-8 byte 순서, 점으로 나눈 카드 번호의 숫자·접미사 순서를 한 번만 정의한다
