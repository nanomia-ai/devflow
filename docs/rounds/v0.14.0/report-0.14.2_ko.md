## 3. 소유자 결정 3건 (2026-08-13, 선택지+프리뷰로 확정)

1. **혼합 요청 = 기록에서 분리** (DD-65). 기록 줄은 게이트 탈락 항목만 담고, 통과 항목은 그
   대화에서 경량 차선이 처리한다. 카드 동승안은 "경량은 어떤 기록도 만들지 않는다"와 정면
   모순이라 기각(최초 권장안이었으나 소유자 원칙 대조에서 철회), 내구 항목 목록안은 새 상태
   기계라 보류.
2. **같은 파일 동시 = 양보 규칙 게이트** (DD-66). 편집 전 대상 경로 검사 + 커밋 직전 대조 +
   물러나는 쪽은 경량 고정. 검사~커밋 사이 race는 잠금 없이는 닫히지 않음을 README 보장 밖
   표에 등재.
3. **glossary = 능동 판단형 조건부 읽기.** 경직된 열거 대신 방향("이름·용어에 닿을 수
   있으면")과 싼 기본값("불확실하면 읽는다 — 작은 문서다")으로. 기록은 생기지 않는다 — 읽기
   입력만 늘어난다.

### 4.1 수리분 재감사 결과 — 그리고 루프의 종료

수리 문장만 대상으로 한 유계 독립 패스: **소견 5 · 소실 클래스 0 · 깨끗 판정 14영역**
(공기록 공격·즉시 기록×준비 라우팅 공격·승인 예외×코드 금지 공격 등이 전부 버팀). 다섯
전부 같은 라운드에서 수렴형으로 수리했다:

| # | 갈림 | 수렴 수리 |
|---|---|---|
| 1 | 항목 단수 대조 기준 × 단위별 묶음 커밋 | 대조 기준을 "이 커밋이 묶는 항목들"로 |
| 2 | 뒤집힌 항목의 잔여가 2사례 어디에도 없음 | 셋째 사례 명명: 되물렸다 커밋 뒤 재적용(형제 묶음 항목 제외를 명시) |
| 3 | 처리 완료 항목에 기록 행 재점화 → 루프/정지 | 행 술어에 "차선이 이 대화에서 이미 처리한 항목 아님(보존은 그 커밋)" 추가 |
| 4 | 반전 창이 확인 국면을 제외 + 확인 실패 처분 무명 | 창을 "읽기·수정·확인 어느 국면"으로, 실패 처분 한 문장(항목 안 수리, 뒤집히면 전환) |
| 5 | work "커밋 하나" × 정본 "단위당 하나" | work를 "단위마다 하나, 정본 규칙 그대로"로 정렬 |

수리 후 자기 점검이 정밀도 하나를 추가로 잡아 같이 닫았다(2번 문안의 "카드에 속하지 않는
세션 수정"이 형제 묶음 항목까지 포섭할 여지 — 뒤집힌 항목의 잔여로 한정). 기계 검사 재통과
95/95.

**루프 종료 선언.** 패스 계보: 독립 2패스 소견 16(중복 제거) → 수리 15 · 유계 재감사 소견
5 → 수리 5+1 · 소실 클래스는 전 패스에서 0. 재감사의 수리는 전부 수렴형(기준 재범위·사례
명명·술어 보완·기수 정렬)이고 해석을 새로 여는 문장이 없다 — 사전 고정한 §5 종료 조건이
충족되어 여기서 텍스트 검증을 멈춘다. 다음 검증 수단은 텍스트가 아니라 실전이다.
