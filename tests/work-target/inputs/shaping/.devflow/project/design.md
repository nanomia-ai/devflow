# Status-card design

The page should feel operational rather than promotional. One compact card contains a quiet label,
the delivery ID, a plain-language state, the latest event, and retry timing when applicable.

- State text and an accessible label carry meaning; color is secondary.
- Failure is unmistakable without using alarming animation or oversized warning treatment.
- The primary state and next useful fact should scan before metadata.
- Review `src/status.html` at a narrow 420 px viewport and a normal desktop width.
