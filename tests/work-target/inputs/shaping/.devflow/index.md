# Relay Desk project map

Relay Desk is a small operator page for reading one delivery's current state.

## Foundation readiness

- Product is ready at `project/product.md`.
- Architecture is ready at `project/architecture.md`.
- Design applies and is ready at `project/design.md`.
- No Adoption is active.

## Question routes

- Operator meaning and product boundary → `project/product.md`
- File boundary and verification channel → `project/architecture.md`
- Visual hierarchy, status expression, and review surface → `project/design.md`
- Current Work → immediate `work/*/state.md`, then the selected sibling `spec.md`

Enumerate only immediate active state. Git owns implementation bytes and history.
