# Queue Relay project map

Product is ready only when `project/product.md` states the problem, users, boundary, non-goals,
language, cross-domain shape, invariants, and open questions. File existence alone is not readiness.
Architecture begins only after Product is complete.

Product questions route through the active project Sketch. Find active state only at
`sketches/*/state.md`, `adoption/state.md`, and `work/*/state.md`. Resume compares the selected state
with current Git state, then reads its sibling brief and only the foundation path needed by its next
route.

Conversation and incomplete canonical files are not current foundation truth.
