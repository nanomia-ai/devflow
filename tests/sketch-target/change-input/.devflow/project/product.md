# Product: Ledger Pocket

Ledger Pocket lets one person add, list, and correct durable text entries from a command line. A
backup is a portable, human-readable representation of the user's entries for safekeeping or later
import. Shared ledgers, cloud synchronization, and graphical interfaces are outside the product.

The [Entries Domain](domains/entries/index.md) owns entry identity and content rules. Product owns
the promise that a backup preserves user-meaningful entry data, not storage implementation details.
No product question is open.
